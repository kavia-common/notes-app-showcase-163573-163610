# Notes App Presentation – Slidev

This Slidev presentation showcases the features and user experience of a modern notes application with a horizontal, visually engaging layout.

Brand Colors:
- Primary: `#2D81FF`
- Secondary: `#FFBB00`
- Accent: `#F40076`

Features demonstrated:
- Horizontal slide navigation with header titles and progress
- Table of Contents navigation
- Embedded screenshots and videos
- Demo slides for creating and editing notes (using Monaco Run)
- Light, modern visual style

Getting Started:
- `pnpm install` (or `npm install` / `yarn`)
- `pnpm dev` (or `npm run dev` / `yarn dev`)
- Visit http://localhost:3030

Build / Export:
- `pnpm build` to build SPA
- `pnpm export` to export to PDF/PNG

Edit the [slides.md](./slides.md) to iterate on the deck.
Learn more about Slidev at the [documentation](https://sli.dev/).
